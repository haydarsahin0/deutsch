# Deutsch mit Melo – video pipeline (shared spec)

Every agent works against this spec. If you need to change it, keep it backward compatible and note the change here.

## Look
- 1920×1080, 30 fps, H.264 + AAC, horizontal YouTube video, 10–15 min.
- Style = the chosen mascot **Concept B** (`brand/concepts/b/melo-b.js`) and the banner (`brand/channel/banner.html`, `brand/out/youtube-banner.png`): warm paper, black ink with variable width, hatching, stipple, paper grain, muted vintage colours (mustard #E0A93B-ish, watermelon red, greens, navy/charcoal). Display type Fraunces Black / Anton / Oswald, handwriting Caveat / Kalam (all in `brand/fonts/`).
- Melo stands in front of a big board (dark-green chalkboard or paper whiteboard in the banner's classroom). Everything on the board appears **as if being drawn/written right now** (stroke reveal, handwriting reveal), and gets **erased** (eraser/sponge wipe) when the topic changes. Camera moves: wide, close-up on Melo, zoom into board, slow drift.
- **Lip sync rule:** the mouth moves ONLY while Melo is speaking (inside word intervals AND above a loudness gate). In pauses the mouth is closed (or holds the expression's resting mouth). No flapping on breath noise.

## Episode folder
```
episodes/<NN-slug>/
  script.md            # source of truth: spoken German + inline cues (written by script team)
  sprechtext.md        # generated: clean text for the voice actor (cues stripped)
  audio/teil-1.mp3, teil-2.mp3, …   # AI voice (ElevenLabs v3) parts, delivered one by one
  audio/voice.wav      # generated by tools/assemble-audio.py (parts joined + scripted long pauses inserted)
  build/alignment.json # words with start/end + resolved cue times
  build/envelope.json  # per-frame loudness for lip sync
  build/timeline.json  # final resolved timeline the renderer consumes
  out/video.mp4, out/subtitles.de.srt, out/subtitles.de.vtt
```
`audio/` and `out/` large files are not committed if > 90 MB.

## script.md format
YAML front matter, then the spoken text with inline cues in double square brackets. A cue fires at the start time of the **first spoken word after it** (or at the end of the previous word if nothing follows). Text outside `[[...]]` is exactly what gets spoken. Markdown headings (`## ...`) are section labels only (not spoken).

```
---
title: "Das sagt kein Deutscher!"
level: B1–C1
---
## Hook
[[scene layout=melo]] [[melo expr=smirk pose=idle]]
Stell dir vor: Juli, 35 Grad. [[draw type=wrong id=w1 text="Ich bin heiß."]] Und du sagst zu deiner Kollegin: Ich bin heiß. [[melo expr=surprised]] [[pause s=1]]
```

### Cue vocabulary
| cue | meaning |
|---|---|
| `[[scene layout=board\|melo\|split\|title]]` | new scene; board content of previous scene is erased (eraser wipe) |
| `[[camera shot=wide\|melo\|board\|close focus=<id>]]` | camera move (eased, ~0.8 s) |
| `[[melo expr=<deadpan\|smirk\|talking\|surprised\|unimpressed\|annoyed\|laughing> pose=<idle\|finger\|point\|explain\|crossed\|chin\|shrug> look=<board\|viewer\|left\|right>]]` | character state (any subset); `finger` = raised index finger (concept-sheet hero stance) |
| `[[draw type=title text="..."]]` | big handwritten heading on the board |
| `[[draw type=wrong id=.. text="..."]]` | sentence written, then crossed out in red (strike follows ~0.6 s later unless `strike=manual`) |
| `[[draw type=right id=.. text="..."]]` | correct version, green tick |
| `[[draw type=word id=.. article=der\|die\|das word="..." plural="..."]]` | vocab card, article colour (der blue, die red, das green) |
| `[[draw type=sentence id=.. text="..." highlight="part"]]` | example sentence, highlighted part underlined/coloured |
| `[[draw type=note id=.. text="..."]]` | small handwritten side note / arrow comment |
| `[[draw type=bubble id=.. who=left\|right text="..."]]` | speech bubble (mini dialogue) |
| `[[draw type=list id=.. items="a\|b\|c"]]` | list written item by item (each item appears on the next `[[next id=..]]` or all at once if `stagger=auto`) |
| `[[draw type=icon id=.. name=sun\|beer\|coffee\|clock\|house\|heart\|question\|... ]]` | hand-drawn doodle |
| `[[next id=..]]` | reveal next item of a list |
| `[[strike id=..]]`, `[[highlight id=..]]`, `[[tick id=..]]`, `[[erase id=..]]` | act on an element |
| `[[quiz id=.. q="..." options="a\|b\|c" answer=<index> seconds=5]]` (answer index is **0-based**) | "Kernfrage": question + options + countdown; answer revealed on `[[reveal id=..]]` |
| `[[reveal id=..]]` | reveal quiz answer |
| `[[voice tag="…"]]` | delivery direction for the AI voice only (ElevenLabs audio tag); renderer ignores it (rig may use it as an expression hint) |
| `[[pause s=1.5]]` | the speaker pauses (shown as "(Pause)" in sprechtext); visuals keep going |
| `[[sfx name=pop\|swoosh\|chalk\|erase]]` | optional sound effect (later) |

Unknown cues must be ignored with a warning, never crash.

## Voice (ElevenLabs) and audio assembly
The narration is generated with ElevenLabs v3 from `tts-elevenlabs/teil-N.txt` (made by `tools/sprechtext.js`; `[[voice tag="…"]]` cues become `[tag]` audio tags there and are invisible elsewhere). The voice does NOT hold long pauses, so:
`python3 tools/assemble-audio.py episodes/<ep>`: joins all `audio/teil-*.{mp3,wav}` in order (trim edge silence, 0.35 s gap), aligns, then INSERTS real silence for every `[[pause s=…]]` with s ≥ 2 (quiz countdowns) at the end of the word before the cue, writes `audio/voice.wav` (48 kHz mono) and the shifted `build/alignment.json`. If only some parts exist, the episode is built up to the end of the available audio (partial build); cues after it are dropped.

## Alignment
`tools/align.py episodes/<ep>`: transcribe `audio/voice.*` with faster-whisper (German, word timestamps), align the transcript to the spoken text of `script.md` (fuzzy, tolerant of small reading deviations), output `build/alignment.json`:
```
{ "duration": 742.3,
  "words": [ {"i":0,"text":"Stell","start":0.52,"end":0.71}, ... ],   // script words, times interpolated if unmatched
  "cues":  [ {"cue":"scene","args":{...},"word":0,"t":0.52}, ... ],
  "sentences": [ {"text":"...","start":..,"end":..}, ... ] }
```
Also writes `out/subtitles.de.srt|vtt` (max 2 lines × 42 chars, 1–7 s each, split at sentence/clause boundaries).

Additive fields (backward compatible, details in `tools/ALIGN.md`): `partial`, `covered_until_word`; words also carry `raw` (display form with punctuation), `match`, `line`, `para_end`; cues carry `at` (`start`|`end`), `line`, `prev_end`; sentences carry `words:[first,last]`; `sections` (`## headings` with time); `subtitles` `[{start,end,lines,words:[first,last]}]` (the same chunking as the SRT, for burn-in); `nonword_sounds` (chuckles/laughs outside words); `inserted_pauses`; `stats` (match rate, deviations, pause self-check). Unquoted numeric cue args are numbers (`s=5` → `5`). When voice.wav and `build/voice-manifest.json` match, `align.py` reuses the cached per-part transcripts (fast re-align after a script edit).

## Lip sync envelope
`tools/envelope.js episodes/<ep>` → `build/envelope.json` `{fps:30, rms:[...] }` one normalised value per video frame.

## Rendering
`node tools/build.js episodes/<ep>` runs: sprechtext → align → envelope → timeline → render → mux. The renderer is a self-contained HTML page with `window.renderFrame(t)`; Playwright captures frames in parallel workers and pipes them to ffmpeg. `--from/--to` seconds for partial renders, `--preview` for 960×540 fast drafts.

# Visual flow v2 (owner feedback 2026-11-11 — supersedes the "board-centric" look)

The owner rejected the static classroom look. **Goal: short-form retention in a long video.** Something new must happen all the time; everything that is mentioned is SHOWN (illustrated, written, or acted out).

## Rules for every episode
- **New shot every 3–6 s** on average; never more than ~8 s on the same composition without a visible change (new element, camera push/pan, character reaction). Typical episode of 11–12 min ≈ 150–220 shots.
- **Show, don't just tell:** situations in the script („Büro ohne Klimaanlage“, „Schwiegermutter, Kartoffelsalat“, „Biergarten“, „Keller, Kartons“) get a full-frame illustrated scene with characters acting it out. Quotes are spoken by the characters in speech bubbles.
- **Melo is a presenter, not wallpaper:** visible roughly 40–60 % of the time, in varied ways: (a) `corner` narrator (small, ~30–35 % frame height, bottom-left/right), (b) `side` next to the board/text (~45–55 % height, never bigger), (c) `in-scene` as a participant (he often plays the learner who says the wrong sentence), (d) `walk-in`/`peek` gags, (e) `off` — not on screen. **No more huge close-ups**; the closest shot is a medium shot (head + torso, head ≤ 35 % of frame height), used rarely for punchlines.
- **Shot types mix** (rotate them; avoid the same type twice in a row more than 2×): illustrated scene, kinetic typography, wrong-vs-right split, board/notebook explanation, list/grid, map, quiz, chapter card, Melo-medium.
- Transitions are mostly fast **cuts**, with occasional ink-wipe, whip-pan, paper-slide, zoom-through for chapter changes; eraser wipe only on the board.
- Text on screen is short (≤ 8 words per element) and big enough for phones.
- Burned-in subtitles stay (bottom), so keep the bottom ~170 px free of essential content.

## New cues (added to the vocabulary; old cues still work)
| cue | meaning |
|---|---|
| `[[shot type=scene set=<setName> cast="<id>:<slot>:<expr>, …" melo=<off\|corner-left\|corner-right\|side-left\|side-right\|in-scene:<slot>> in=<cut\|ink\|whip\|slide\|zoom> cam=<wide\|push\|pan-left\|pan-right\|tilt>]]` | full-frame illustrated situation. `cast` places supporting characters into the set's slots (`left`, `center`, `right`, `back`, `table-left`, … as defined by the set). |
| `[[shot type=text style=<wrong\|right\|big\|question\|stack> text="…" sub="…" melo=… in=…]]` | kinetic typography full-frame (words slam/pop in on the word timing; `wrong` = red strike, `right` = green tick) |
| `[[shot type=split left="…" right="…" leftLabel="…" rightLabel="…" melo=…]]` | wrong (left, red) vs. right (right, green) comparison |
| `[[shot type=board melo=<side-left\|side-right\|off\|corner-…>]]` | the chalkboard/notebook for explanations (rules, tables); subsequent `draw` cues write on it |
| `[[shot type=list title="…" melo=…]]` | full-frame list/grid; items via `draw type=list` / `next` |
| `[[shot type=map map=dach melo=…]]` | Germany/Austria/Switzerland map; labels via `[[pin id=.. at=<bayern\|rheinland\|schwaben\|wien\|schweiz\|norden\|…> text="…"]]` |
| `[[shot type=chapter num=<n> title="…"]]` | chapter card („Nr. 3 – Ich habe 25 Jahre“) |
| `[[shot type=melo framing=<medium\|wide> bg=<color\|set>]]` | Melo talking to camera (medium at most) |
| `[[shot type=quiz …]]` | quiz full-frame (uses the existing `quiz`/`reveal` cues) |
| `[[cast id=<castId> expr=<…> pose=<…> talk=<on\|off>]]` | change a supporting character's state in the current scene |
| `[[say who=<castId\|melo> text="…"]]` | speech bubble from a character (in scenes). The bubble appears on the word timing; the speaker's mouth moves while the narrator speaks that quote. |
| `[[prop id=.. name=<iconOrPropName> at=<slot\|x,y> anim=<pop\|drop\|wiggle>]]` | put a prop/icon into the current shot |
| `[[fx name=<shake\|flash\|zoom-punch\|sweat\|steam\|hearts\|question-marks\|sparkle\|record-scratch>]]` | small comedic effects |
`draw`, `strike`, `tick`, `highlight`, `note`, `quiz`, `reveal`, `pause`, `voice`, `melo` cues keep working inside any shot (they target the current shot's content area).

## Sets (full-frame illustrated backgrounds; registry `engine/sets/sets.js`, one file per set `engine/sets/<name>.js`)
API: `Sets.render(name, {t, seed, variant})` → full 1920×1080 SVG string (layers: `bg`, `fg` optional overlay drawn in front of the cast), `Sets.slots(name)` → `{left:{x,y,scale}, right:{…}, …}` (feet positions + scale for cast/Melo), `Sets.list()`. Static parts must be cacheable (pure function of seed/variant; `t` only for small ambient motion like a fan, steam, flicker).
Initial sets for episode 1: `office-hot` (open office, broken AC, fan, sweating plants, thermometer 35°), `dinner-table` (family dinner, potato-salad bowl, plates), `cellar` (dark cellar, cardboard boxes labelled with years), `winter-room` (broken radiator, frost window, scarf), `living-room` (apartment, door, couch), `cinema-front` (cinema entrance at night, posters), `football-park` (park football, nostalgic sepia variant), `biergarten` (tables, chestnut trees, beer mugs), `supermarket-checkout` (checkout, ice-cream freezer), `doctor-office`, `doorstep` (front door + pizza delivery), `quiz-show` (studio, spotlights, buzzer podiums), `kneipe` (pub at night), `job-interview` (office desk, two chairs), `bakery` (counter, pretzels, bread), `after-work-desk` (desk at night, monitor glow), `park-bench` (break-up mood, autumn), `university` (lecture hall), `laptop-email` (close-up laptop screen with an email UI), `wg-kitchen` (shared-flat kitchen, phone with pizza app), `exam-room` (desks, clock), `map-dach` (stylised DACH map with Bundesländer outlines; used by `shot type=map`), `board` (the existing classroom/chalkboard set).
